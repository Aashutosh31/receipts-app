# Receipts

Receipts is a 90-day accountability app ("winter arc"). It targets CONSISTENCY,
never body punishment.

## Getting Started

1. Copy `env.example.json` to `env.json` and fill in your Supabase URL and
   anon key (never commit `env.json`).
2. Run the app:

```sh
flutter run --dart-define-from-file=env.json
```

3. See `docs/SUPABASE_SETUP.md` for backend setup (migrations, Email auth,
   finding URL and anon key).
4. See `docs/PROGRESS.md` for stage status and `docs/DECISIONS.md` for
   ambiguous-requirement decisions.
